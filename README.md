# Micro X Engine

Мінімальний вертикальний прототип 3D-рушія для **MIDP 2.0 / CLDC 1.1** і
JSR-184 (M3G). Рушій використовує Q12 fixed-point для симуляції, fixed-step
оновлення, пул сутностей і портальну видимість без кадрових колекцій.

## Вимоги та статична збірка

Потрібні JDK 8 (для старого `-source 1.3`), Apache Ant, Sun Java Wireless
Toolkit 2.5.2 або сумісний Java ME SDK і JSR-184 `jsr184.jar`. Шляхи у
`build.properties` розраховані на стандартний WTK layout.

```sh
export WTK_HOME=/opt/WTK2.5.2
ant -Dwtk.home="$WTK_HOME" clean jar
```

Ціль викликає CLDC preverifier, пакує `res/` та створює
`micro-x-engine.jar` і `micro-x-engine.jad`. Профілі у маніфесті:
`MicroEdition-Configuration: CLDC-1.1` та `MicroEdition-Profile: MIDP-2.0`.
Запуск у WTK:

```sh
"$WTK_HOME/bin/emulator" -Xdescriptor:micro-x-engine.jad
```

## Керування

`2/8` — вперед/назад, `4/6` — поворот, `1/3` — стрейф, `5` — постріл,
`7` — приціл, `9` — присідання, `0` — стрибок, `#` — зброя, `*` — КПК,
права soft key — пауза. Подвійне натискання або утримання `2` вмикає біг.

## Формат рівня і обмеження прототипу

`level.txt` — текстовий whitespace-separated формат із magic `MXL1`,
кількістю кімнат/порталів, місткістю пулу, прямокутними межами кімнат,
напрямленими portal edges, стартом гравця та записами сутностей. Рядки й
залишки рядків після `#` є коментарями, тому рівні можна читати, редагувати та
переглядати у GitHub. Тест містить дві кімнати з переходом, різницею висоти
підлоги і pooled-ціль. Геометричний M3G-файл можна замінити без зміни симуляції.

Поточна версія має AABB-зіткнення і просту ступінчасту підлогу, портали не
обрізаються екранним frustum, hit-scan використовує циліндричні хітбокси,
немає анімації, збережень, мережі, динамічного світла чи повноцінного AI.
Runtime-фізика та AI не використовують floating point; `float` лишається
тільки на межі API JSR-184 для камери.
